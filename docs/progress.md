## 当前题目：BM91 - 反转字符串

**难度**: 入门  
**分类**: 双指针  
**通过率**: 65.45%  
**题目链接**: https://www.nowcoder.com/practice/c3a6afee325e472386a1c4eb1ef987f3

### 题目描述
编写一个函数，其作用是将输入的字符串反转过来。

**示例1:**
```
输入: "hello"
输出: "olleh"
```

**示例2:**
```
输入: "abcdef"
输出: "fedcba"
```

### 解题思路
这是一道经典的双指针题目，有多种解法：
1. **双指针法**: 使用两个指针分别指向字符串的开头和结尾，交换字符后向中间移动
2. **内置函数法**: 直接使用编程语言提供的反转函数
3. **递归法**: 递归地反转子字符串

### 推荐解法
建议使用双指针法，这样可以练习双指针技巧，时间复杂度O(n)，空间复杂度O(1)。
